# XKeen Add-ons

Дополнения для ручного выбора VLESS-серверов на ARM64 Keenetic: обновление и смена подписок, проверка HTTPS-соединения через выбранный сервер, интеграция с XKeen Panel и восстановление списка после повреждения файла.

Скачать установщик непосредственно на роутер после установки Entware и XKeen:

```sh
curl -fL https://raw.githubusercontent.com/ixarek/xkeen-addons/main/install-xkeen-addons.sh -o /opt/tmp/install-xkeen-addons.sh
sh /opt/tmp/install-xkeen-addons.sh --check
```

Затем следуйте разделу «Новая установка» ниже.

Один файл `install-xkeen-addons.sh` устанавливает команды `xsub`, `xserver`, `xsub-guard`, локальный HTTP-сервер подписки, автозапуск панели и резервное сохранение её списка серверов. При отсутствии скачивает XKeen Panel v1.3.0 и xkeen-subscription-watcher v0.4.0 из официальных GitHub Releases с проверкой SHA-256. Установленные бинарники не обновляет.

Установщик предназначен для ARM64/aarch64 Keenetic с уже установленными Entware, XKeen 2.x и Xray. Требуется доступ к интернету и не менее 32 МиБ свободного места в `/opt`. USB-накопитель не требуется, если Entware установлен во внутреннюю память. Ваших паролей, аккаунта панели и подписок в файле нет.

## Новая установка

1. Установите Entware, XKeen и Xray штатным способом.
2. Сохраните установщик на компьютер. Из PowerShell, находясь в папке с файлом, скопируйте его на роутер:

```powershell
scp -O .\install-xkeen-addons.sh root@192.168.1.1:/opt/tmp/
ssh root@192.168.1.1
```

3. В SSH сначала проверьте требования:

```sh
sh /opt/tmp/install-xkeen-addons.sh --check
```

4. Для новой стандартной конфигурации XKeen выполните:

```sh
sh /opt/tmp/install-xkeen-addons.sh --configure-routing
xsub change
xserver
```

`xsub change` запросит HTTPS-ссылку подписки скрытым вводом. В `xserver` выберите сервер по номеру. Именно при ручном выборе будет проверена итоговая конфигурация и перезапущен Xray.

Опция `--configure-routing` заменяет `05_routing.json` после резервного копирования: локальные IP-адреса идут напрямую, трафик стандартных входов `redirect`, `tproxy`, `force-proxy-redirect`, `force-proxy-tproxy` — в `vless-reality`. Эта опция предназначена для стандартного набора входов XKeen. Она заменяет пользовательские правила маршрутизации; для существующей настроенной системы запускайте установщик **без этой опции**.

5. Откройте `http://192.168.1.1:3000`. На новой панели создайте собственный аккаунт и выполните её начальную настройку. В интерфейсе Keenetic разрешите нужные каналы интернета для политики XKeen и назначьте ей устройства. Установщик не меняет каналы WAN/Wi-Fi и назначения устройств.

## Использование

```sh
xsub change       # Сменить исходную HTTPS-ссылку и загрузить список
xsub update       # Обновить список у провайдера по сохранённой ссылке
xserver           # Список и интерактивный ручной выбор
xserver list      # Только список
xserver ping 51   # Проверить HTTPS-запрос через сервер 51
xserver use 51    # Выбрать сервер 51
```

В интерактивном меню `xserver`: число переключает сервер, `p 51` проверяет его, `q` выходит. Номера могут меняться при обновлении подписки. Проверка показывает время полного HTTPS-запроса через прокси, а не ICMP-пинг. Кнопка «Пинг» в самой панели использует её собственную реализацию проверки.

После `xsub change`/`xsub update` обновите страницу панели. Её ссылка подписки — `http://127.0.0.1:18080/vless.txt`: это локальная подготовленная копия. Кнопка обновления панели перечитывает её; загрузку у провайдера выполняет `xsub update`. Не заменяйте локальную ссылку в панели ссылкой исходного неподдерживаемого формата.

Поддерживаются обычные URI-списки и Base64-подписки с VLESS. В панель попадают только VLESS; другие протоколы не преобразуются в VLESS и сохраняются в исходном скачанном файле. Форматы JSON/YAML, ссылки на личный кабинет, зашифрованные подписки и специальные схемы вроде `happ://` этим установщиком не поддерживаются. TLS-проверка сертификатов не отключается.

Автоматическое переключение серверов и периодическая загрузка подписки не включаются. При смене подписки текущая работающая конфигурация Xray сохраняется до ручного выбора другого сервера. Если прежнего сервера нет в новой подписке, его активная отметка в списке снимается.

## Резервное сохранение

Перед установкой создаётся каталог `/opt/etc/xserver/install-backup-ДАТА-ВРЕМЯ-PID`. Состояние списка защищает `/opt/sbin/xsub-guard`: проверка при запуске панели, снимок перед штатной остановкой и проверка раз в минуту через cron. На flash пишутся только изменённые исправные снимки. При повреждении файла панель восстанавливает последнюю исправную копию. Аварийная потеря питания до создания снимка может потерять последние изменения.

Исходная ссылка хранится в `/opt/etc/xserver/source-url` с правами только для root. Список и его резервная копия тоже содержат секреты подключения — не публикуйте их.

## Разработка

Исходники команд находятся в `scripts/`, шаблон установщика — в `tools/installer.template.sh`. После правок пересоберите единый файл в PowerShell:

```powershell
pwsh -File tools/build.ps1
```

Используемые сторонние проекты скачиваются отдельно, их бинарники не входят в этот репозиторий:

- [XKeen](https://github.com/jameszeroX/XKeen)
- [XKeen Panel](https://github.com/Dearonski/xkeen-panel)
- [xkeen-subscription-watcher](https://github.com/tkukushkin/xkeen-subscription-watcher)

## Что проверено

Команды обновления, выбора, HTTPS-проверки и восстановления повреждённого файла проверены на исходном ARM64-роутере. Для самостоятельного установщика дополнительно выполнены проверка синтаксиса BusyBox ash и запуск режима `--check`. Полная установка на чистом роутере в этой сессии не выполнялась.
