# Keenetic TUN Panel

Один установщик для **Mihomo TUN + Zapret Web-GUI** на Keenetic ARM64 с Entware на USB.
Это текущий вариант с веб-интерфейсом, сменой подписки, конвертацией серверов и выбором устройств.
XKeen, старые `xsub`/`xserver`/`mtun` и отдельная панель на порту 3000 больше не устанавливаются.
Предыдущий вариант сохранён в Git-теге `legacy-cli-2026-10-09`.

## Что нужно подготовить

1. Установить Entware **на USB-накопитель** средствами Keenetic.
2. Восстановить обычный интернет и доступ к SSH Entware.
3. Подготовить HTTPS URL подписки.

Поддерживаемая сборка: **aarch64 / ARM64**, `/dev/net/tun`, LAN `br0`, минимум 256 МБ свободно на USB.
Рабочая исходная конфигурация проверена на KeeneticOS 5.1.7. Совместимость с другими моделями/прошивками не заявлена.
Скрипт не форматирует накопитель и не устанавливает Entware или компоненты KeeneticOS.

## Установка

В SSH Entware от root выполните:

```sh
curl -fLsS https://raw.githubusercontent.com/ixarek/xkeen-addons/main/install.sh -o /tmp/keenetic-tun-install.sh && sh /tmp/keenetic-tun-install.sh
```

Если `curl` ещё не установлен: `opkg update && opkg install curl ca-bundle`.
Скрипт нужно сохранить в файл и запускать интерактивно: ввод пароля и URL скрыт.

Установщик:

- проверяет USB, архитектуру и наличие TUN;
- устанавливает необходимые пакеты Entware;
- скачивает закреплённые версии GUI и Mihomo, проверяет SHA256;
- запрашивает пароль панели, URL подписки и включать ли всю домашнюю сеть;
- конвертирует Base64/URI-подписку или принимает Clash YAML с `proxies`;
- проверяет конфигурацию настоящим Mihomo, запускает ядро и находит первый сервер, прошедший HTTPS-тест;
- включает выбранный режим маршрутизации, автозапуск и показывает адрес панели.

На новой установке можно согласиться на TUN для всей LAN-подсети или назначить устройства позже.
Повторный запуск сохраняет существующие DNS, правила, устройства и пароль; обновляет список серверов из указанной подписки.
На время установки ядро и панель останавливаются. Ошибка приводит к восстановлению прежних файлов.
Пакеты, уже установленные через opkg, при откате остаются.

Панель доступна по `http://<LAN-IP-роутера>:8080/#mihomo`, логин `admin`, пароль вы задаёте при установке.
Привязка к LAN-IP, API ядра и смешанный прокси слушают только localhost. Порт наружу пробрасывать не требуется.

## Обычное управление в браузере

**Подписка:** Mihomo → Инстансы → «Подписка для home-tun».
Вставьте другой URL → «Сохранить и применить». Для прежней ссылки нажмите «Обновить серверы».
При ошибке скачивания или проверки прежний список остаётся; при ошибке перезапуска выполняется попытка восстановления прежнего конфига.

**Сервер:** Mihomo → Прокси → выбрать строку → «Через эту». «Тест всех» проверяет задержку через ядро.

**Добавить устройство:** Маршрутизация → «+ Маршрут» → Устройства → «Выбрать из сети…».
Метод: `Туннель: mihomo · mihomo-tun`, включён → Сохранить.
Для всей сети используйте её подсеть, например `192.168.4.0/24` (установщик определяет фактическую подсеть).
Домены, CIDR назначения, списки и geosite/geoip для такого маршрута оставьте пустыми.

**Убрать устройство из TUN:** отредактируйте маршрут и удалите его из «Устройства»; сохраните.
Если действует маршрут всей подсети, удаление отдельного адреса из другого маршрута его не исключит: замените подсеть списком нужных устройств.
Можно выключить или удалить весь маршрут — клиент останется в домашней сети.

**Остановить ядро:** Mihomo → Инстансы → home-tun → Остановить.
Чтобы оно не запускалось после перезагрузки, снимите галочку «автозапуск».
Панель продолжит работать. Kill-switch на странице Маршрутизация управляется отдельно: его включение может блокировать интернет при остановленном ядре.

**DNS:** Mihomo → Инстансы → home-tun → Редактировать.
В блоке `dns` по умолчанию:

```yaml
  nameserver:
    - https://8.8.8.8/dns-query#PROXY
    - https://9.9.9.9/dns-query#PROXY
```

После правки: «Проверить (mihomo -t)» → Сохранить → Restart.
Это резолвер Mihomo. DNS клиентов, обращающихся к самому Keenetic, настраивается отдельно.

## Что означает TUN здесь

Mihomo получает IPv4-пакеты через `mihomo-tun`; GUI применяет маршрутизацию устройств в таблицу 233.
Сам роутер и локальные сети остаются доступны напрямую. Внешний выход — сервер из подписки.
TUN не превращает VLESS/Trojan в универсальный IP VPN: поддержка TCP/UDP зависит от протокола и сервера;
работа ESP/GRE и конкретного корпоративного VPN не гарантируется.

IPv6 на WAN/LAN и DNS к самому роутеру могут идти другим путём. Установщик не отключает IPv6 на всём роутере
и не утверждает отсутствие всех утечек. Kill-switch по умолчанию не включается.
Для IPv4 маршрут подтверждается `ip rule show`, `ip route show table 233`,
`ip route get 1.1.1.1 from <IP-клиента> iif br0`, счётчиками `ip -s link show mihomo-tun`.

## Диагностика и восстановление

```sh
sh /tmp/keenetic-tun-install.sh --check
sh /tmp/keenetic-tun-install.sh --restore /opt/var/backups/keenetic-tun/КАТАЛОГ-КОПИИ
```

Путь копии выводится перед заменой файлов. Копия содержит приватные настройки: не публикуйте её.
Скрипт восстанавливает файлы своего списка и запускает сохранённые сервисы; после ручного отката проверьте маршруты в панели.
Лог панели: `/tmp/zapret-gui-server.log`; ядра: `/opt/var/log/mihomo-home-tun.log`.

Обновлять эту сборку нужно повторным запуском **этого установщика**.
Обновление GUI через штатный updater может затереть нашу форму подписки и исправление автозапуска.
Фоновая проверка обновлений отключена установщиком; ручные кнопки обновления сторонних компонентов остаются в GUI.
Скрипт не удаляет другую ранее установленную систему проксирования: на новом USB её быть не должно;
для миграции с другого установщика сначала отключите его сервисы и маршруты.

## Источники и сборка

- [Zapret Web-GUI](https://github.com/avatarDD/zapret-gui), MIT, версия 0.25.8,
  commit `bcffb595af46bac72727c8a5b05ea82635b58efa`.
- [Mihomo](https://github.com/MetaCubeX/mihomo), GPL-3.0, версия `v1.19.32`.
  Бинарник скачивается из официального релиза и не включён в репозиторий.
- `addon/` — четыре доработанных файла GUI: форма и конвертер подписок, регистрация API, исправление автозапуска через nohup.
- `tools/` — исходники установщика. `python tools/build.py` создаёт самодостаточный `install.sh` со встроенными доработками.
- `tests/` — проверка конвертации, отката подписок, конфигурации и сборки. GitHub Actions также проверяет BusyBox ash и настоящий Mihomo.

Конвертер сохраняет имена серверов. Для VLESS XHTTP преобразует основные параметры и XMUX в формат Mihomo;
два дополнительных параметра производительности Xray используют значения Mihomo по умолчанию с предупреждением.
Неподдерживаемые записи пропускаются и учитываются в результате. Доступность каждого типа транспорта требует отдельного теста.

В репозитории нет пользовательских URL, паролей, ключей и готовых приватных конфигов.
Установщик создаёт их на USB с правами 600, резервные копии — в каталоге 700.
Наличие оболочки Zapret Web-GUI не означает установку nfqws2: эта сборка устанавливает **Mihomo TUN**.
